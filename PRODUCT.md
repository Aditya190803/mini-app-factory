# Product

## Register

product

## Users

Builders who want to turn a natural-language product idea into a working web application without assembling the frontend, backend, database, and deployment workflow themselves.

## Product Purpose

Mini App Factory is a conversational full-stack app builder. It helps users create, inspect, refine, preview, and deploy portable applications whose generated backend uses Cloudflare Workers and Cloudflare data services when the product requires them.

## Brand Personality

Capable, direct, transparent. The product should feel like a trustworthy workshop: active and technical without becoming theatrical or cryptic.

## Anti-references

Avoid fake progress, hidden work, generic chatbot chrome, decorative AI gradients, excessive terminal cosplay, and interfaces that conceal file changes or deployment consequences. Lovable and v0 are workflow references, not visual templates to copy.

## Design Principles

1. Show observable work and concrete outcomes.
2. Keep chat, preview, code, and deployment in one continuous workflow.
3. Make generated projects portable and based on standard platform tooling.
4. Require explicit confirmation before creating billable or persistent cloud resources.
5. Preserve a recoverable project version after every successful build.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard operation, visible focus, semantic status announcements, reduced motion, sufficient contrast, and status indicators that do not rely on color alone.
